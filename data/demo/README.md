# DEMO DATA — NOT REAL GAME RESULTS

`DEMO_DATA_NOT_REAL_rounds.csv` is **synthetic**. It was generated by
`npm run seed:demo` (`lib/demo.ts`) from independent random draws of a
crash-style distribution with a 3% house edge (P(X ≥ m) ≈ 0.97 / m).

- It exists only for development and testing.
- It must never be presented as real Aviator / Betika data.
- Because draws are independent, it contains **no predictive signal**. A
  correctly working pipeline should report *"No statistically meaningful
  predictive edge detected."* on it.

In the app, demo rows are stored with `is_demo = true` and are analysed
separately from real data — the two datasets are never mixed.
